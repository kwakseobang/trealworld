## 스텝 7. 남은 열린 질문 4개를 닫음

- **요청**: 열린 질문을 물어보면 답하겠다.
- **질문 (AI)**: 4개를 목록으로 보여주고, 첫 번째(백엔드만인가)를 물었다.
- **답 (사용자)**: 4개를 한 번에 답했다.
  1. 백엔드만 한다.
  2. 원본과의 호환은 중요하지 않다. 아이디어만 가져온다.
  3. Spring Boot 최신 버전, Java 25, Gradle Kotlin DSL, JPA, H2, Lombok, JUnit, ArchUnit.
  4. 가입 → 로그인 → 회원 정보 조회.
- **한 일**: 킥오프 문서 6.5~6.8에 기록했다. 처음의 열린 질문 7개가 모두 닫혔다.
- **결정의 영향**
  - 답 2가 아이디어 D(원본 Hurl 테스트를 수용 테스트로 쓴다)를 폐기시켰다. 문서에서 취소선으로 표시했다. 지우지 않았다.
  - 기술 스택은 사용자가 직접 정했다. AI가 대안을 비교하지 않았다.
- **관찰**
  - AI는 질문을 하나씩 물으려 했다. 사용자는 목록을 보고 한 번에 답했다. 답이 이미 있는 질문은 묶어서 묻는 편이 빠르다.
  - "호환이 필요 없다"는 답이 접근 전체를 바꿨다. 원본은 "따라야 할 계약"에서 "아이디어의 출처"가 됐다. 처음에 AI는 호환을 당연한 것으로 가정했다.
  - 폐기한 아이디어를 지우지 않고 남겼다. 무엇이 왜 버려졌는지가 과정의 기록이다.
