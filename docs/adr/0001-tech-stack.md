# ADR-0001. 기술 스택

- 상태: 승인 (사용자가 결정, 2026-11-16). 수정 (2026-11-17): 프로젝트를 만들 때 확인한 버전을 적었다. 수정 (2026-11-17, 작업 4, 작업 5, 작업 6): 더한 의존성을 적었다. 수정 (2026-11-17): RFC 2119와 ASD-STE100의 원칙으로 다시 썼다. 의존성의 규칙과 Bean Validation의 금지는 "결과"에서 "결정"으로 옮겼다 (일지의 스텝 43). 승인 (2026-11-17, 스텝 54): 작업 4 ~ 6에서 AI가 더한 의존성과, AI가 옮긴 규칙을 사용자가 AI의 권장대로 받아들였다. 하나씩 보지는 않았다. 목록은 일지의 스텝 54에 있다.
- 읽는 법: 굵게 쓴 **반드시 ~해야 한다**(MUST), **절대 ~해서는 안 된다**(MUST NOT), **~하는 것을 권장한다**(SHOULD), **~할 수 있다**(MAY)는 RFC 2119의 뜻이다. 표는 [Spec 01](../spec/01-member-signup-login.md#이-문서를-읽는-법)에 있다. 굵은 말이 없는 문장은 설명이다.

## 맥락

이 프로젝트는 백엔드만 만든다. 원본과의 호환은 필요 없다. 예제보다 process가 중요하다.

## 결정

이 프로젝트는 아래의 스택을 **반드시** 써**야 한다**.

| 항목 | 선택 |
|---|---|
| 프레임워크 | Spring Boot 4.1.2 (2026-11-17의 최신 안정 버전) |
| 언어 | Java 25 |
| 빌드 | Gradle 9.9.1 (wrapper), Kotlin DSL |
| 영속성 | JPA |
| DB | H2 (인메모리) |
| 보조 도구 | Lombok |
| 테스트 | JUnit, ArchUnit |

의존성의 규칙:

- 의존성은 그 의존성을 쓰는 작업에서 **반드시** 더**해야 한다**. 쓰기 전에 미리 더하지 않는다.
- 더한 의존성은 이 문서에 **반드시** 적**어야 한다**.
- Bean Validation은 **절대** 써**서는 안 된다**. 값의 규칙은 **반드시** `domain`에 두**어야 한다**.
- 기본 패키지는 **반드시** `trealworld`**여야 한다**.

더한 의존성:

| 작업 | 의존성 | 쓰는 곳 |
|---|---|---|
| 2 | ArchUnit 1.5.1 | 아키텍처 테스트 |
| 4 | `spring-security-crypto` | 비밀번호의 해시 |
| 5 | `spring-security-oauth2-jose` | JWT의 발급 |
| 6 | `spring-boot-starter-security` | 필터 체인 |
| 6 | `spring-security-oauth2-resource-server` | Bearer 토큰의 필터, JWT의 검사 |

## 결과

- 대안을 비교하지 않았다. 사용자가 익숙한 스택을 골랐다.
- Spring Boot의 버전은 Spring Initializr(start.spring.io)의 기본값에서 확인했다. SNAPSHOT과 RC는 뺐다.
- H2는 인메모리다. 서버를 다시 시작하면 데이터가 사라진다. 시연에는 충분하다.
